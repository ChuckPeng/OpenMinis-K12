# 平板加密备份

## 职责

把错题、FSRS 状态、本机事件、配置与 `child_id` 端到端加密后上传。服务端不能解密。不含聊天原文。

## 分期

| 批次 | 范围 |
| --- | --- |
| v1 M0 | 向导收集备份口令 |
| v1 M5b | 每日备份与换机恢复 |
| 后置 | 服务端数据库自身的异地复制（T-46），不是本模块 |

## 公开接口

| 调用 | 说明 |
| --- | --- |
| `PUT /api/v1/device/backups` | 上传密文 |
| `GET /api/v1/device/backups/latest` | 换机时取回密文 |

口令经 Argon2id 派生密钥，AES-GCM 加密。文件头、关联数据与分块见 T-31。KDF 参数随 `device_backup.kdf_params` 存放，便于以后改参数，但不能让服务端据此解密。

## 数据

备份内容仅限上一节列出的项。模型 Key 若包含在「配置」里，也只在密文中（§19.4：备份中加密保存）。聊天记录不进备份。

触发：每天一次，充电且联网。保留由服务端执行：7 个日备份 + 4 个周备份。

## 依赖

同步客户端的设备签名、存储模块的密文对象、首次设置的口令。

## 状态与流程

1. 本机打包。
2. 加密。
3. 上传，服务端核对大小与 SHA-256 后落盘。
4. 新平板在向导选择恢复，输入口令，得到原 `child_id`，然后重新配对。

每学期至少演练一次恢复（测试计划）。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 口令错误 | 解密失败，不写入半份数据，不上传口令 |
| 上传中断 | 保留上次成功备份。不把残缺对象标成 latest |
| 服务端不可达 | 本机留待下次充电联网再传。不阻断学习 |

## 配置

无家长可调的保留档。口令只在家长侧修改；修改后的新备份用新密钥，旧密文仍可用旧口令解开，直到过期删除。

## 验收

没有单独字母编号。对应 §19.6：服务端库与对象存储中看不到明文 `child_id` 以外的学习内容；口令不出现在日志；恢复后 `child_id` 不变。服务端自身备份的 R9 不在本模块。
