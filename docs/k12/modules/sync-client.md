# 同步客户端

## 职责

平板上唯一访问 OpenMinis-K12 服务端的组件。负责设备签名、心跳、事件、任务、报告拉取、备份传输、APK 清单与诊断。不访问企业微信或钉钉。

## 分期

| 批次 | 范围 |
| --- | --- |
| v1 M5b | 配对之后的全部设备 API，除任务与完整报告 |
| v1.1 M5e | `GET /api/v1/device/reports`（孩子版） |
| v1.2 M5d | `GET /api/v1/device/tasks` 与附件。验证未通过时仍可有本机任务，只是不同步钉钉 |

## 公开接口

契约：`api/device-api.yaml`。传输只用 `public_base_url` 的 HTTPS，在家和在外同一地址。用 `NetworkHttp.client`（H-17）。配对时固定的证书指纹不符则拒绝（J11）。

签名头：`X-K12-Device`、`X-K12-Ts`（Unix 毫秒）、`X-K12-Nonce`（32 位小写十六进制）、`X-K12-Sig`。签名字节串是五行，用换行连接：大写方法、路径（含查询串）、时间戳、nonce、正文 SHA-256 的小写十六进制。空正文哈希空字节。时间窗 ±5 分钟。

周期：WorkManager。事件平时每 5 分钟或满 100 条上传，日简报前 15 分钟强制一次。每批最多 500 条，gzip。心跳带上 `config_version_applied`、App 版本、当日用量、权限自检结果。

## 数据

本机保存：`public_base_url`、证书指纹、中继公钥、`device_id`、已应用配置版本、已消费的 `grant_id`、未确认的事件。不保存企微密钥、解锁码、`parent_advice_json`、告警片段。

## 依赖

Keystore 中的设备私钥、存储模块的服务端、家长管控要应用的配置。

## 状态与流程

离线时使用最后一次配置。事件在本机排队。解锁申请不排队（见解锁模块）。告警与日简报材料排队，恢复后补发并标注延迟。

心跳返回的服务器时间用于校时。偏差超过 2 分钟时，之后的事件仍记设备时间，由服务端修正（数据模型）。

发现新 APK：下载后校验签名与 SHA-256，再提示安装。网页可暂停或回滚某一版本。

诊断上传不含聊天、题目原文与图片。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 指纹不符、签名被拒、设备已吊销 | 停止重试该请求，家长区显示离线或已吊销 |
| 429 | 按响应退避。设计未写 `Retry-After`，没有则使用本地指数退避 |
| 配置版本落后 | 应用新 `config_json` 后回报版本 |
| gzip 或单批超过 500 | 拆批。不丢弃未确认事件 |

## 配置

服务端地址来自配对，家长可在解绑后重配。无第二套隐藏端点。

## 验收

J1、J5、J11，以及 S8、S14 中与上传和孩子版报告有关的部分。H2 的排队在本模块与通知模块共同完成。

## 未决

无。长轮询无变化时仍返回当前 JSON，`changed` 为 false。
