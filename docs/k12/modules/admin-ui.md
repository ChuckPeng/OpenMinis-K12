# 管理界面

## 职责

家长用的网页：安装向导、企微、设备与孩子、报告、告警片段、钉钉、模型、条目库、审计。Vue 3 + Vite + TypeScript，构建后嵌入 Go 二进制。不采用 htmx。

## 分期

| 批次 | 页面 |
| --- | --- |
| v1 M5a | 向导、企微、管理员登录、日志与审计骨架 |
| v1 M5b | 设备、家长、解锁记录、告警、孩子与配置、日简报计划、系统状态 |
| v1.1 | 完整报告、图表、导出、报告设置 |
| v1.2 | 钉钉、班级消息、模型测试 |
| M5f | 亲子建议条目库 |

## 公开接口

`api/admin-api.yaml`。浏览器只谈管理端口。会话 Cookie：HttpOnly、SameSite=Strict；空闲 30 分钟，绝对 12 小时。写请求要 CSRF。CSP 要严。

认证：argon2id。同一账号或来源 15 分钟内失败 5 次，锁定 15 分钟。忘记口令用 CLI `reset-admin`。无 TOTP（T-46 才考虑）。

当 `public_url` 为 https，或可信代理传来 `X-Forwarded-Proto=https` 时，Cookie 加 Secure。向导若发现公网访问却不是 HTTPS，要警告。

## 数据

不另建业务表。读取存储模块的表。查看告警片段写审计。Secret 与 Key 只写不回显。

## 依赖

存储、通知、报告、钉钉、模型网关。反向代理终结 TLS。

## 状态与流程

向导顺序：设口令 → 填企微 → 测 token → 复制回调 URL / Token / AESKey → 等待 URL 校验 → 添加家长 → 生成第一个配对码。

系统状态页显示：队列积压、企微送达失败、超过 24 小时未心跳、配置未生效。指标只有计数与时延。

日志脱敏。设计原文「脚敏」按脱敏实现。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 未登录 | 管理 API 拒绝（R6） |
| 缺 CSRF | 写请求拒绝 |
| 非可信来源伪造 `X-Forwarded-For` | 不影响限速 |
| 公网端口打到管理路径 | 404（R7） |

## 配置

时区默认 `Asia/Shanghai`。`trusted_proxies`、`public_url`、保留期、限流、管理员口令在设置页。强口令规则见 T-27。
