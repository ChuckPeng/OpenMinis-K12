# 课程目录与知识图谱

## 职责

用三层技能描述「怎么教」和「教到哪」，不内置课文。家长拍照目录或词表，整理成 `catalog.md`。图谱只在本机、运行时下载。

## 分期

| 批次 | 范围 |
| --- | --- |
| v1 M1 | `study-companion-core`、学生档案模板、首批样例 catalog、装进官方 Minis 的说明 |
| v1 M3 | catalog 节点与图谱 id 的映射，供先修回溯 |
| v1.1 | 词表供听写口语使用 |
| 后置 M6 | 生地模块。考务日期由家长填写并自行核对 |

首批科目已决定：初中数学 + 英语词表；小学语文、数学、英语。

## 公开接口

| 层 | 内容 |
| --- | --- |
| `study-companion-core` | 分层提示、不代写整篇、超纲标记、休息提醒等红线 |
| `student.md` | 每台平板一份。模板无姓名，实例不进仓库 |
| `catalog.md` | 学科 × 年级。章—节—知识点—要点—难度—进度 |

技能安装走上游 `SkillRepository`（H-18）。提示词里最多 20 条技能，沿用上游上限。

## 数据

仓库只放模板与不含个人数据的样例。家长生成的 catalog、词表、映射文件在本机私有目录。NC 数据不进 git、不进 APK。衍生映射保持 CC BY-NC-SA。

版本俗称在 catalog 里做别名。具体出版社由家长在档案里选，文档不写某一家庭的版本。

## 依赖

上游技能加载。辅导与错题只读 catalog。拍照结构化复用 `read_image`，家长在 PIN 后的家长区操作。

## 状态与流程

1. 家长拍摄目录或词表。
2. 模型整理成结构，家长抽查后写入。
3. 壳层激活本机这一份 student 与 catalogs。v1 不支持同一平板切换孩子。
4. 需要先修时，用已下载图谱；非图谱覆盖的版本只靠 catalog，不假装对齐。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 结构化结果不像目录 | 不覆盖旧 catalog，要求重拍或手改 |
| 图谱下载失败 | 缓存策略未写（T-52）。不得把图谱文件提交进仓库 |
| 技能条数超过 20 | 遵循上游截断，文档说明取舍，不改上游常量除非单独立项 |

## 配置

会考等区域模块默认关，由家长在档案打开。高中 catalog 不在 v1。

## 验收

课标-D1–D4（不要与钉钉-D 混淆，T-01）。
