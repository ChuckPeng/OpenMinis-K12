# 解锁

## 职责

在提示链走完之后，让家长远程批准单题或 15 分钟，或使用备用码。本机 PIN 与 TOTP 不经过本模块也能揭晓。

## 分期

| 批次 | 范围 |
| --- | --- |
| v1 M2 | 本机 PIN、可选 TOTP。申请按钮先是 PIN 弹窗 |
| v1 M5b | 远程申请、长轮询、授权验签、备用码、卡片更新 |
| M5c | 加时申请卡片（T-42） |

## 公开接口

| 方法 | 路径 |
| --- | --- |
| `POST` | `/api/v1/device/unlock-requests` |
| `GET` | `/api/v1/device/unlock-requests/{id}?wait=25` |
| `POST` | `/api/v1/device/unlock-requests/{id}/ack` |

请求体：`client_request_id`、`subject`、`question_hash`、`hints_used`、可选理由。不传题目原文。

授权字段见数据模型。平板用配对时的服务端公钥验签，并核对 `device_id`、题目哈希、未使用过的 `grant_id`。

备用码：6 位，`HMAC(codeSecret, 请求号 ‖ 题目哈希)` 截取。服务端算好放进卡片。平板只持有 `codeSecret`，离线校验，不显示码。单次、10 分钟、错 5 次冷却 10 分钟。

TOTP：RFC 6238，30 秒。只在平板与家长的验证器之间。同码只用一次。与服务端无关。

## 数据

`unlock_requests`、`grants`、`nonces`。状态：`pending` → `approved` / `denied` / `expired` → `consumed`。

## 依赖

配对、通知（卡片与 `update_template_card`）、辅导状态机、企微回调。

## 状态与流程

限流：每台设备同时 1 个待处理，每小时不超过 10 个。时间戳 ±5 分钟，nonce 缓存 10 分钟。

家长按钮：批准本题 / 解锁 15 分钟 / 拒绝（T-19）。任一可审批家长即可。非绑定家长无效（J7）。

回调 5 秒内回空包，按 `TaskId` + `EventKey` 幂等。然后用一次性 `response_code`（72 小时）更新卡片。

长轮询 25 秒一轮，直到申请过期。无变化时的正文见 T-30。连不上则 5 秒内提示改用 PIN / TOTP。

10 分钟无人处理：请求过期，卡片改为已过期。解锁类消息过期不补发。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 服务端不可达 | 不排队申请。PIN / TOTP 仍可用（G4、J6） |
| 重复回调 | 不签发第二个授权（J3） |
| 授权转到别的设备或别的题 | 拒绝（J5） |
| 已用 PIN 或备用码 | `ack` 后服务端关闭申请并更新卡片 |

## 配置

申请有效期 10 分钟。15 分钟档的时长是按钮含义的一部分。作业/考试模式是否允许远程解锁，遵循辅导模块：仅家长解锁后可出。

## 验收

G1–G5，J2–J9。J1、J10–J13 在配对与通知模块。
