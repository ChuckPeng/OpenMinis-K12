# 钉钉同步

## 职责

家长在服务端网页扫码一次，用自己的钉钉账号做用户级授权。服务端只读已绑定班级群里老师或管理员的消息，抽取成作业、通知、待办、考试，推到对应孩子的平板。平板不登录钉钉，不向群发送任何内容。

## 分期

v1.2，且仅当钉钉-D1–D4 全部通过。不通过则本模块不编码，只保留拍照/截图录入（路线图 WP-D-4b）。

M7 的作业计划以后消费这里的任务，不在本模块做估时与专注计时。

## 公开接口

管理 API 以 `api/admin-api.yaml` 为准：授权二维码与状态、解除授权、绑定、消息、任务、立即同步、重新抽取。

设备 API：`GET /api/v1/device/tasks?since=&wait=25`，`GET /api/v1/device/attachments/{id}`。只返回该设备 `child_id` 的条目。

平板只显示、勾选完成、到期提醒。不回写钉钉。完成事件用 `task_done`。

## 数据

`dingtalk_account`、`child_group_binding`、`class_message`、`extracted_task`。令牌加密。非老师消息不入库、不进日志、不送模型（钉钉-D8）。

原文与附件保留 30 天，任务 180 天。单个附件默认不超过 20 MiB，可在设置里改。

## 依赖

模型网关、通知（失效提醒与摘要）、存储、同步客户端。先实现方案 A（用户级 OAuth 直调）。只有钉钉-D1–D4 证明 A 不可用时才改用 dws（Apache-2.0）。封装 dws 时只放行读命令，send 类命令在代码层拒绝；其 Linux 构建依赖 glibc，不能用 Alpine。在 D1–D4 有结论前不写功能代码。

## 状态与流程

1. 网页显示二维码，家长用钉钉确认。最小读权限。
2. 每个孩子绑定一个或多个群，以及唯一平板。加孩子、换机、换群只改绑定，不重新扫码。
3. 每个群只拉一次，再按绑定分发。
4. 增量游标，按消息 id 去重。
5. 抽取失败则把老师原文标成未结构化投递，稍后重试。
6. 授权失效：企微提醒，同步暂停，拍照兜底仍可用。

拉取：白天每 60 分钟，16:00–22:00 每 10 分钟，周末只用 60 分钟。须满足钉钉-D4 的余量（不超过实测上限的 50%）。

老师：群主或管理员，或出现在家长维护的名单里。两者满足其一即可。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 刷新令牌失败 | 状态改为需重新授权，停止拉取 |
| 接口限流或连续失败 | 退避。超过阈值提醒家长 |
| 两个孩子绑不同群 | 平板不得看到另一群（钉钉-D6） |
| 家校群不可读 | 记录原因，启用兜底，不伪造任务 |

## 配置

授权、绑定、老师规则、拉取计划和保留期都在管理页。企微摘要默认每天 20:47 一份，当天没有新条目则不发。

## 验收

钉钉-D1–D12，以及 L2 在抽取失败时的投递。
