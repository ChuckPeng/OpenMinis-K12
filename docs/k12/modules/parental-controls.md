# 家长管控与儿童模式

## 职责

PIN 保护设置与模型 Key；儿童锁裁剪危险入口；只统计本 App 内时长；平板家长区只留本机设置与解锁兜底。报告、亲子建议和多数策略在企业微信与服务端网页。

## 分期

| 批次 | 范围 |
| --- | --- |
| v1 M0 | PIN、入口裁剪、每日时长、休息提醒、家长区骨架 |
| v1 M2 | 揭晓策略的本机执行（策略内容在辅导模块） |
| v1 M5b | 展示服务端下发的配置版本；用量上限；远程解锁的兜底入口 |
| 不做 | 其他 App 的管控；平板上的家长报告页；v1 同一平板多孩子 |

## 公开接口

| 接口 | 说明 |
| --- | --- |
| PIN 门 | 守卫 H-04 点名的路由，以及 H-05、H-06 的旁路入口 |
| 工具拒绝 | `AgentToolSwitch` 与 `OffloadGate`（H-07、H-08） |
| 时长 | 在 `MinisApp` 前后台回调计时（H-11）。不用 `UsageRecord` |
| 配置只读视图 | 显示已应用的 `config_version`。修改在网页 |

家长区（PIN 后）：PIN/TOTP、配对、模型 Key、catalog 拍照、解锁兜底、权限自检。

## 数据

`ParentSettings` 见数据模型。时长用尽写 `limit_reached`。屏幕时长与 token 用量分开。

已决定的默认时长：

| 学段 | 每日 | 周末 | 连续使用休息 |
| --- | --- | --- | --- |
| 小学 | 40 分钟 | +30 | 25 分钟 |
| 初中 | 90 分钟 | +30 | 40 分钟 |

高中不在 v1 实现。家长可改数字，改完以服务端版本为准。

## 依赖

导航与生命周期挂钩、同步客户端（心跳）、解锁模块（兜底）。内容安全负责话题，本模块负责入口。

## 状态与流程

儿童锁默认开。无 PIN 不能改供应商、Key、揭晓策略、通知通道（E1）。时长用尽后锁定入口，家长可加时（E3）。加时的远程卡片属 M5c（T-42）；v1 至少支持本机 PIN 加时。

离开家长区是否立即上锁，以及 5 分钟无操作超时，见 T-22。未确认前按该建议默认实现，并在 PR 里点名。

禁用清单以 `upstream-patches.md` 为准。蓝牙与 HomeKit 在本 Android 树中没有对应控制接口。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 服务端配置拉不到 | 沿用上次生效的版本 |
| PIN 连续错误 | 设计未写 PIN 的锁定次数。解锁码的「错 5 次冷却」不自动套到 PIN 上 |
| 时钟大步跳变 | 当日时长不回绕成负数；异常记诊断日志，不含使用内容 |

## 配置

归属见 §19.4：时长、休息、深夜、揭晓策略、用量上限、学段在服务端；PIN 与模型 Key 在平板。用量默认见 T-09。陪伴时长不计入学习时长。

## 验收

E1–E3。E4 的日简报在报告模块，周报在 v1.1。E5 在通知模块。C4 在本模块。F1、F2 与内容安全共同验收。
