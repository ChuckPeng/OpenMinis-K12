# 学情报告与指标

## 职责

把平板事件按天聚合成日简报、周报、月报、学期报告和随时查看。只和该孩子自己的过去比。孩子看得到同一份数字和图表，看不到亲子建议。

## 分期

| 批次 | 范围 |
| --- | --- |
| v1 M2–M4 | 只在平板记事件（分属辅导、错题、听说） |
| v1 M5b | 上传、`study_event`、`daily_aggregate`、模板日简报、最简签名报告页 |
| v1.1 M5e | 十项指标、分析、周报及更长报告、图表与导出、孩子端、配置页 |
| v1.2 | 任务指标开始含钉钉来源 |
| M5f | `parent_advice_json` 由亲子建议模块写入。本模块负责不把它发给设备 |

## 公开接口

| 调用 | 说明 |
| --- | --- |
| `POST /api/v1/device/events` | 设备签名。按 `event_id` 幂等，返回已收最大 `seq` |
| `GET /api/v1/device/reports` | 仅本机孩子。响应不含 `parent_advice_json` |
| `GET /r/{link_id}` | 公网端口。HMAC、未过期、未撤销。过期只提示登录，不泄露数字 |
| 管理 API | 列表、随时生成、撤销链接、删除一段数据、报告设置 |

企微卡片只带最少数字。页面 `noindex`、`no-referrer`，不加载第三方资源。图表用 ECharts（Apache-2.0）打进二进制，不走 CDN。导出 PDF 用打印样式；长图在浏览器生成。服务端不跑无头浏览器。

## 数据

表见 `data-model.md`。报告只从 `daily_aggregate` 与 `kp_daily` 读。`metric_version` 变化后不改旧报告，环比只在同一版本之间做。

## 依赖

同步客户端、通知、模型网关（摘要，可关）、存储。钉钉任务在 v1.2 之前，相关分母为空。

## 指标口径

| # | 指标 | 要点 |
| --- | --- | --- |
| 1 | 时长 | 学习界面前台内，每次交互把活跃延长 60 秒。有效 = 活跃区间并集，不超过前台结束。空闲 = 前台 − 有效。后台与锁屏不计。连续 15 分钟无交互结束会话。陪伴单列，不计入学习 |
| 2 | 任务 | 完成率分母 = 期内到期任务 + 期内创建且无截止的任务。按时率只算有截止时间的。钉钉只算作业与待办。通知与考试不进该分母。逾期完成记「完成但逾期」 |
| 3 | 正确率 | 首次作答、未用提示才算首次正确。拍题讲解不进正确率，只进指标 5。科目少于 10 题或知识点少于 5 题显示「样本不足」 |
| 4 | 错题 | 按题目哈希去重。待复习含逾期。清零率 = 已订正 ÷（期初未订正 + 新增） |
| 5 | 提示与揭晓 | 每题最高状态按 guide、hint、step 计 1–3，未提示为 0。揭晓率分母是进入 `reveal` 的题，分子不含复盘查看 |
| 6 | 听说 | 听写按词。背诵按句，取最好一遍。v1.1 口语只计次数与时长，不写分数 |
| 7 | 掌握度 | 近 30 天首次作答，半衰期 14 天指数加权正确率 × 0.7 + 该点错题 FSRS 可提取率均值 × 0.3。无错题只用前一项。尝试少于 3 次不定级。精通 ≥0.85，良好 ≥0.65 且 <0.85，合格 ≥0.40 且 <0.65，其余薄弱 |
| 8 | 连续天数 | 有效时长 ≥ 10 分钟或完成至少 1 次到期复习。家长设定的休息日不打断 |
| 9 | 深夜与超长 | 深夜默认小学 21:00、初中 22:00 到次日 06:00。超长 = 连续有效学习超过休息阈值且中间没有 ≥ 5 分钟休息 |
| 10 | 情绪旗标 | 只计次数、级别、时间与已通知。不含原文 |

日界：家庭时区，04:00。跨午夜算前一学习日，并计入深夜。周为周一至周日。日简报默认只在周一至周五。

分析：日简报对比前 7 天日均；上期学习日少于 3 天则不对比。薄弱点取本期尝试 ≥ 3 的前 5，公式见设计 §18.3。错因五类。

摘要：输入只有去标识数字与目录名称，孩子称「孩子」。输出里每个数字必须来自输入。失败则模板。文字来源要标在报告上。日简报只用模板。v1.1 起周报及更长报告默认也用模板，家长打开后才调用大模型。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 设备超过 2 小时未同步 | 卡片写明数据截至何时 |
| 全天无事件 | 「今日未使用或未同步」 |
| 迟到 ≤ 30 天 | 重算。已发报告标已修订。关键数字变化超过阈值（有效时长 ±10%，或完成率/正确率 ±5 个百分点）时在下一份日简报附一句，不另推 |
| 模型不可用 | 照常发送，文字标模板（S11） |
| 链接被改、过期、撤销 | 打不开，且无数字（S13） |

## 配置

§18.8。推送时刻、接收人、指标开关、学段参数、提醒阈值、文字来源、链接有效期（默认 72 小时）、时区与日界、学期起止（只手填）。关闭「情绪」只影响报告，即时告警照常。默认时刻：日简报 20:47、周报周日 19:47、月报每月 1 日 19:47、学期结束次日 19:47。

提醒阈值默认不即时推送：正确率下降 ≥ 15 个百分点；非休息日连续 3 天未学习；深夜 ≥ 20 分钟；揭晓率 ≥ 40%；逾期复习 ≥ 15；钉钉作业按时率低于 80%。每项可改为同时推送。
