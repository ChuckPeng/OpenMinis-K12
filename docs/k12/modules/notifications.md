# 通知与企业微信

## 职责

所有给家长的外发消息：解锁卡片、告警、日简报与更长报告、配对确认、钉钉摘要。先入 outbox，再经转发代理调用企业微信。

## 分期

| 批次 | 范围 |
| --- | --- |
| v1 M5a | 客户端、回调加解密、outbox、模板、J12 |
| v1 M5b | 解锁卡片、三级告警、模板日简报 |
| v1.1 | 周报及更长报告的卡片 |
| v1.2 | 钉钉作业摘要 |
| M5c | 加时、家长任务、可选 H5 |

不使用群机器人、PushPlus、Server酱。

## 公开接口

企微 API 基址可配，默认 `https://qyapi.weixin.qq.com`。实际填转发代理。`gettoken` 缓存，提前 5 分钟刷新，单飞；`40014` / `42001` 强刷并重试一次。token 不下发。

回调：`GET` / `POST` `{public_base_url}/wecom/callback/{callback_key}`，经 HTTPS 反向代理进设备端口。GET 在 1 秒内解密 `echostr` 并原样返回。POST 验 `msg_signature`，AES-256-CBC 解密后核对 corpid。5 秒内先回空包。出站 `gettoken` / `send` / `update` 仍走固定公网 IPv4 的转发代理，发送量不超过官方额度的 50%。

只使用企业微信 App 才能看到按钮。微信插件只发文本。消息最小化：类型、家长标签、时间、级别、备用码。不含题目原文、聊天原文、真实姓名（J8）。

告警消息不含片段。片段在网页查看，前后各至多 2 句（H4）。

## 数据

`wecom_apps`、`parents`、`outbox`、`templates`、`schedules`、`audit_log`。告警行在 `alerts`，本模块负责推送与合并。

退避：1 分钟起，上限 1 小时，24 小时后放弃并在网页告警。解锁类过期即丢。

## 依赖

存储、管理界面的配置页、解锁状态机、报告模块产生的正文。

## 状态与流程

| 事件 | 形态 | 按钮 |
| --- | --- | --- |
| 解锁申请 | 按钮卡片 + 文本版 | 批准本题 / 解锁 15 分钟 / 拒绝 |
| 情绪告警 | 文本通知型卡片，发给全部家长。紧急告警在孩子选择之前就发 | 可选「我已知晓」 |
| 日简报及更长报告 | 文本卡片，链到报告页 | 无 |
| 新设备 | 按钮卡片 | 确认 / 拒绝 |

告警同一会话 30 分钟内同级合并。失败时平板本机通知兜底。紧急告警不因孩子点了「不想说」或尚未选择而取消。

按钮回调（J12）是 M5a 的第一项开发实测。若 `template_card_event` 到不了回调 URL，一键批准不作为主路径：同一申请改为文本通知加 6 位备用码，家长把码告诉孩子。PIN 与 TOTP 不变。实测结果写入该工作包，不再问所有者。

日简报默认 20:47，且默认只在周一至周五。应用低活跃可能被停用：每日发送用来保持活跃；收到 `inactive_alert` 等事件时在网页提醒。官方未公布天数，不把它写成需求。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 代理故障 | 进 outbox。平板告警排队并标注延迟 |
| 回调重试 | 幂等，不重复授权 |
| 非可审批家长点击 | 无效（J7） |
| 频率接近上限 | 不超过官方额度的 50%，再超则 429 |

## 配置

Secret、Token、EncodingAESKey 只在服务端。管理页根据 `public_base_url` 显示回调 URL 供复制。默认应用名「伴学助手」，可见范围默认只有可审批的家长。

## 验收

J1、J3、J4、J6–J8、J10、J12、J13，H1–H3，R2、R3、R5、R11。E5：抽测 1 分钟内送达。

| 编号 | 标准 |
| --- | --- |
| H6 | 紧急告警一旦成立就发企微，不等待孩子点「不想说」或别的选择。两种选择下家长都收到 |
| J14 | M5a 第一项记下按钮回调是否到达。若否，文本加 6 位备用码仍能完成一次批准 |
