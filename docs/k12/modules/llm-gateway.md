# 服务端模型网关

## 职责

服务端调用家长配置的 OpenAI 兼容 Chat Completions，只做三件事：

1. 把老师消息抽取成作业、通知、待办、考试。
2. 写报告的白话摘要、三条建议和孩子版鼓励语（只输入去标识数字）。
3. 在亲子建议的候选条目里选取并改写。

讲题、辅导全部留在平板的 Minis 模型层。本网关的 Key 不下发。

## 分期

| 批次 | 用途 |
| --- | --- |
| v1.1 M5e | 报告文字。可关闭，关闭后全用模板 |
| v1.2 M5d | 通知抽取。与报告共用同一配置 |
| M5f | 亲子建议改写 |

v1 的日简报不用本网关。

## 公开接口

| 方法 | 路径 |
| --- | --- |
| `GET` / `PUT` | `/api/v1/admin/llm` |
| `POST` | `/api/v1/admin/llm/test` |

配置：Base URL、API Key（只写不回显）、模型名、超时。规划不指定厂商。家长可改为自托管的兼容接口。

抽取输出须通过 JSON Schema：`kind`、`subject`、`title`、`detail`、`due_at`、`attachment_refs`、`confidence`。不合格算失败。无工具调用，无外发权限。

报告与亲子建议的输出形状见各自模块。数字校验在那些模块，调用在这里。

## 数据

Key 存在 `settings`，主密钥加密。按消息哈希去重，避免重复调用。默认每家庭每日 200 次，可在设置里改。

输入不含其他家长的群消息、不含孩子真名。附件图片要 OCR 时再定；v1 不做本地 OCR，抽取默认只用文本与文件名。

## 依赖

钉钉同步提供老师文本。报告与亲子建议提供聚合 JSON。存储负责密钥。

## 状态与流程

超时、HTTP 错误或 Schema 失败：调用方走自己的兜底（原文投递或模板）。抽取的重试：1 分钟起，上限 1 小时，24 小时放弃，成功后补结构化结果。报告文字只重试 1 次。

## 错误处理

失败不阻塞主流程：日简报、周报仍要按时发出；老师消息仍要在一个同步周期内到达平板（L2、S11、P8）。

## 配置

超时与每日上限在管理页。文字生成开关在报告设置，不在本页重复。

## 验收

L1–L4。S10、S11、P2、P3、P8 由调用方验收，本模块提供可替换的测试双份（假模型）。

## 未决

无。厂商与模型名由家长填写，文档不给默认厂商。报告文字默认用模板。
