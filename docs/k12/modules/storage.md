# 服务端存储

## 职责

SQLite、迁移、主密钥、保留期清理、服务端自身的备份与恢复、健康检查。业务规则在各模块，本模块保证落盘与升级。

## 分期

M5a 一次到位：库、迁移、备份 CLI、两种部署的数据目录。其后各模块只加迁移文件。

## 公开接口

| 入口 | 说明 |
| --- | --- |
| `server/internal/store` | 各模块的唯一数据库入口 |
| CLI | `serve`、`migrate`、`backup`、`restore`、`healthcheck`、`reset-admin` |
| `GET /healthz`、`/readyz` | 两个端口都有，无认证。正文只有 `ok` / `unavailable`，不写 token 值 |
| 可选 `GET /metrics` | 只有计数与时延 |

迁移用 `go:embed` 的 SQL，启动时先自动备份再执行。

配置文件与 `OPENMINIS_K12_*` 只放进程参数。业务配置在 `settings` 表。

## 数据

库文件在 Docker 的 `/data` 或 systemd 的 `/var/lib/openminis-k12`。主密钥权限 600，不放进备份文件本体；恢复文档必须写明密钥要另存。

平板备份是另一类对象：`device_backup` 只存密文与 `kdf_params`。本模块不尝试解密。

WAL。纯 Go 驱动 `modernc.org/sqlite`，以便 `CGO_ENABLED=0` 交叉编译。

## 依赖

无业务依赖。部署文件在 `server/deploy/`。

## 状态与流程

升级 = 换二进制或镜像后重启。失败用升级前的自动备份回滚（R10）。管理页或 CLI 可下载加密的服务端备份（SQLite `VACUUM INTO` + 配置），并在另一台主机恢复到设备无需重新配对（R9）。

清理任务按数据模型的保留期删除解锁、告警、审计、事件、钉钉原文、报告。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 迁移失败 | 不对外服务。保留自动备份 |
| 磁盘满 | 健康检查失败，outbox 停止扩张并在日志标明 |
| 主密钥缺失 | 拒绝启动，避免把密文当明文写出去 |
| 时钟回拨 | 不提前删除仍在保留期内的行 |

## 配置

数据目录、主密钥路径、`public_base_url`、`trusted_proxies`、监听端口（默认 8080 与 8081，只绑回环接口）。服务端自身备份默认保留 14 份。
