# 首次设置

## 职责

一台新平板第一次使用时建立 `child_id`、家长 PIN、备份口令，并完成权限自检与配对入口。低年级界面语音优先。

## 分期

| 批次 | 范围 |
| --- | --- |
| v1 M0 | 向导：学段 → `child_id` → PIN 与备份口令 → 权限自检。试拍可以后接 |
| v1 M5b | 扫码或手动配对接到向导末尾；试拍一道题 |
| v1.1 | 低年级朗读题干与主要按钮的语音提示（与听说模块的 TTS 共用） |

## 公开接口

向导是壳层页面，不是服务端 API。完成后本机存在 `ChildIdentity` 与 PIN。配对调用同步客户端。

步骤（§19.12）：选学段 → 生成 `child_id`（UUIDv4）→ 家长设 PIN 与备份口令 → 权限自检 → 扫码配对 → 试拍一道题。

## 数据

只生成 id 与家长当场输入的秘密。不要求填写真实姓名。昵称可选，且只存本机。学段与年级随后以服务端为准。

## 依赖

家长管控（PIN）、备份（口令）、配对、权限自检。无障碍：系统字体放大、足够对比度、TalkBack 可读标签。

## 状态与流程

向导未完成时不进入自由聊天。恢复备份是向导上的另一条路：输入备份口令后沿用原 `child_id`，再重新配对，旧设备在网页停用。

权限自检逐项说明自启动、电池优化、后台活动。心跳只上报四个布尔：`notifications_enabled`、`battery_unrestricted`、`background_allowed`、`exact_alarm_allowed`。不上传设备型号。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 中途退出 | 已生成的 `child_id` 保留，不另造一个 |
| 配对失败 | 向导可完成，之后在家长区重试。本机 PIN 已可用 |
| 备份口令与 PIN 相同 | 设计未禁止。不额外发明规则 |

## 配置

学段枚举见数据模型。高中可选为预留值，选中时提示 v1 不提供高中教法。

## 验收

没有单独字母编号。完成标准：向导能生成 `child_id`；无 PIN 不能离开家长步骤；测试机 B 上能打开自检页并看到未授权项。K3 依赖这里的一机一孩。

## 未决

测试机上系统 TTS 与侧载是否放行，见 T-23。自检只报上面四个布尔，不写厂商菜单的具体路径。
