# 拍题分层辅导

## 职责

拍题后先确认题干，再按壳层状态机分层提示。完整解单独生成，未到揭晓不展示。教法在技能 `study-companion-core` 与学科技能里。壳层不把揭晓交给模型自己判断。

## 分期

| 批次 | 范围 |
| --- | --- |
| v1 M2 | 题干确认、提示链、三档变式、卡住换讲法、拍草稿、本机 PIN/TOTP、泄题检查、评测 v0、本机事件 |
| v1 M5b | 「申请看答案」从 PIN 弹窗改为远程申请。状态机不变 |
| 不做 | 高中教法；本地 OCR（v1 把图交给多模态模型） |

## 公开接口

| 接口 | 方向 |
| --- | --- |
| 揭晓状态机 | 壳层内部。输出当前允许的层级 |
| `buildSystemPrompt` 委托（H-09） | 只附加「当前层级与禁止事项」，不在 `ChatViewModel` 里写规则 |
| `read_image`（H-10） | 拍题与拍草稿 |
| 计算工具 | 数学的数值、方程、化简、因式分解由工具得出。模型只讲思路。v1 实现是 Symja `matheclipse-core` 3.2.0（LGPL-3.0，与仓库 GPL-3.0 兼容）。接口是 `CalcEngine` / `AlgebraCas`；换库只改实现 |
| 解锁模块 | 到达可申请状态后调用。M2 只调本机 PIN/TOTP |

## 数据

本机聊天仍在上游会话库。本模块写入 `session_*`、`active_span`、`attempt`、`hint_used`、`answer_reveal`、`stem_confirmed`、`calc_checked`。不上报题目原文。

## 依赖

课程目录（学段、教材字段）、家长管控（PIN、作业/考试标记）、内容安全（注入与预筛）、M5b 起的解锁与同步。

## 状态与流程

壳层状态（设计里的 L0–L2 与「L3 = 揭晓」已改名；「走完 L1–L3」即走完 guide、hint、step）：

| 状态 | 进入 | 允许输出 |
| --- | --- | --- |
| `confirm` | 新题拍照或输入 | 只显示识别出的题干。可改字或重拍。低年级可朗读。低置信度要求重拍 |
| `guide` | 孩子确认题干 | 复述题意、问思路。不给步骤与答案 |
| `hint` | 求助或答错 | 知识点或第一步方向 |
| `step` | 再次求助 | 关键步骤，留下最后一步 |
| `reveal` | 走完三档提示，且满足 §4.5.1 | 完整解答，并写揭晓日志 |

未到 `reveal`：输出若含与参考答案一致的最终数值、选项或完整算式，则拦截并要求按当前层重写。再失败则显示「这一步先停在这里。请按上面的提示自己写下一步。」

确认题干后写 `stem_confirmed`（只有 `question_hash` 与 `char_count`）。验算写 `calc_checked`（只有 `question_hash` 与 `match`）。

揭晓条件：

| 情形 | 默认 |
| --- | --- |
| 未作答或未走完提示链 | 只给下一级。不可放宽 |
| 已作答且走完提示链仍不会 | 可申请。家长解锁后单题一次 |
| 作业/考试模式 | 无解锁不出完整解 |
| 已提交后的复盘 | 默认可看完整解与讲评 |
| 解锁粒度 | 单题一次。家长可改为限时，默认 15 分钟，离开会话恢复锁 |

每次揭晓记录：题目缩略（本机）、走过的层数、方式（PIN / 解锁码 / TOTP / 远程）。孩子看不到解锁码。

理科：两遍推导或工具验算不一致、题干不确定、超纲、开放题无标准答案时，说不确定并给出「问老师」。该题以 `disposition=pending_check` 记入错题本，出现在日简报，不计入错题与掌握度。超纲要标明。

辅导结束默认 3 道变式：基础、同级、稍难。同一题多次卡住则换讲法。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 识别失败或孩子否认题干 | 停留在题目确认 |
| 泄题检查失败 | 重写；仍失败用固定提示语 |
| 工具不可用或结果不一致 | 「不确定 / 问老师」，不展示不一致的数字 |
| 越狱话术 | 不改变状态机 |

## 配置

揭晓策略、学段由服务端下发（家长可按学段改，红线不可放宽）。高年级「走完提示链自动揭晓」是策略项，默认关。

## 验收

A1–A7，G1–G4。G5 在解锁模块（J1–J13）。门槛见测试计划。

### A4 验算（BLOCK-CAS-1，已接入 Symja）

工具负责数值、代数式是否等价、化简、因式分解、一元方程的解集（顺序无关）。模型或孩子给出的结果与工具不一致时，状态变为不确定，`disposition=pending_check`，并写 `calc_checked`（只有 `question_hash` 与 `match`）。工具拒绝输入、超时、或调用发生在主线程时，同样走不确定，不展示一个新的数字。

等价看的是实数上的函数，不只是化简后的代数式。`(x+1)^2` 与 `x^2+2*x+1`、`2(x+1)` 与 `2*x+2` 是完全等价（`CalcEquivalence.Same`）。`(x+1)^2` 与 `x^2+1` 不等价。

定义域不同则不算完全等价。结果是 `CalcEquivalence.Restricted`，`where` 是两侧条件的对称差，按字符串排序。条件有两种：`x!=1` 表示只有一侧在该点无定义；`x>=0` 表示只有一侧要求这个根式（或对数）有意义。这不是完整匹配，验算走不确定。例子：`(x^2-1)/(x-1)` 与 `x+1` 为 `x!=1`（只在 x≠1 时相等）；`x/x` 与 `1` 为 `x!=0`；`(x^2-4)/(x+2)` 与 `x-2` 为 `x!=-2`；实数上 `sqrt(x)^2` 与 `x` 为 `x>=0`。两侧洞相同，例如 `(x^2-1)/(x-1)` 与 `(x+1)*(x-1)/(x-1)`，仍是完全等价。`simplify` 仍可能消去可去奇点，消去之后的多项式再和 `x+1` 比较才是完全等价。

方程默认只给实数解，空集 `{}` 表示无实数解。`x^2-5*x+6==0` 的解集是 `{2, 3}`，只答 `2` 不算对。`x^2+1==0` 默认是 `{}`，不是 `{-I, I}`。复数解要显式打开：`CasField.COMPLEX`，或 `CasPolicy.field(stage, complexSolutionsEnabled)`。该开关默认关，并且只在学段为高中（`StudyStage.SENIOR`）时生效；小学和初中即使把开关打开也仍是实数解。v1 不教高中，因此产品路径保持实数解。

不交给引擎执行的输入：空串、超过 512 字符、括号嵌套超过 32、`While` / 赋值 / `Import` / 分号程序、`1/0` 这类非有限结果。单次验算预算 2 秒，超时后丢掉该引擎实例。
