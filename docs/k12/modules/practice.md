# 背诵、听写与口语

## 职责

按 catalog 词表做背诵、听写和口语陪练。练习页直接调用 TTS/ASR，不走 shell。v1.1 口语只计次数与时长，不打分。

## 分期

| 批次 | 范围 |
| --- | --- |
| v1 | 无。休息提醒在家长管控，全 App 生效 |
| v1.1 M4 | 本模块全部：TTS、ASR、键盘兜底、可选 sherpa 模型、`drill_result` |
| 不做 | 口语评分（与 §18.2 的冲突见 T-33）；课文原文 |

## 公开接口

| 接口 | 说明 |
| --- | --- |
| `TextToSpeechManager`（H-19） | 系统引擎优先 |
| `SpeechRecognitionManager` | 引擎选择见 T-07 |
| sherpa-onnx | 无可用系统能力时的端侧引擎。模型可选下载（T-20），Apache-2.0 |
| catalog 词表 | 只读 |

可选参考：hanzi-writer、pinyin-pro（小学）、chinese-poetry（只对齐课内篇目，不整包当课文）。均为借鉴，不是 v1.1 必做。

## 数据

`drill_result`：`drill`、`list_id`、`total`、`correct`。`score` 在 T-33 落定前不写。

## 依赖

课程目录、家长管控（时长与休息已在 M0）、同步客户端。无 GMS 的行为在测试机 B 上验证。

## 状态与流程

听写：播报 → 孩子书写或语音 → 比对词表。ASR 不可用时改为键盘。背诵：与篇目逐句对齐，取得分句数，取当次最好一遍。口语：跟读，记次数与时长。

小学低年级：大按钮，提示可朗读。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 无 TTS | 显示文字，并在权限自检里说明 |
| ASR 失败 | 键盘兜底（C2） |
| 模型包下载中断 | 练习仍可用系统引擎或键盘；不把半截模型当可用 |
| 词表为空 | 提示家长先拍词表，不内置课文 |

## 配置

语种跟随科目。模型是否下载由家长确认。休息阈值不在本模块配置。

## 验收

C1–C3。C4（小学 25 / 初中 40 分钟休息）由家长管控在 v1 实现，本模块不重复验收。
