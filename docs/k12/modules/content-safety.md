# 内容安全

## 职责

在没有独立审核服务的前提下，用技能红线、壳层状态机、本机关键词预筛、供应商自带审核、评测与红队把风险压到可验收。不宣称绝对安全。

## 分期

| 批次 | 范围 |
| --- | --- |
| v1 M0 | 危险入口交给家长管控；学生日常机关闭开发者工具 |
| v1 M2 | 红队 v0；题目图片中的文字只当题目数据 |
| v1 M5b | 三级告警上传与通知。识别规则本模块拥有，通道在通知模块 |
| 持续 | 换模型或改技能前重跑门槛 |

## 公开接口

| 接口 | 说明 |
| --- | --- |
| 预筛 | 本机关键词与规则，不依赖网络。命中自伤即按「紧急」处理 |
| 技能红线 | 不代写整篇作业或作文；暴力、色情、跑题拒绝并指向家长或老师 |
| 固定回复 | 任何索要 PIN 或解锁码的说法，回复「请直接问爸爸妈妈」。模型不知道 PIN |
| 告警投递 | 调用通知模块。本模块不持有企微密钥 |

## 数据

预筛词表放在应用内，不含个人数据。告警事件 `wellbeing_flag` 只有级别与类别。片段的存储在服务端告警表，不进报告正文，不进模型。

级别：提示 / 关注 / 紧急。同一会话 30 分钟内同级合并。

## 依赖

辅导状态机、家长管控的入口裁剪、通知、测试计划中的红队集。

## 状态与流程

1. 本机预筛。
2. 命中自伤或危险：停止辅导。孩子端第一步只显示「请马上告诉身边的大人。」并提供「不想说」。与此同时立即通知家长，不等孩子选择。
3. 孩子点「不想说」，或之后的话表明不愿告诉大人：若家长配置了心理援助热线，再显示该文案与号码。未配置则不显示任何号码，仍保留第一句。仓库和安装包不写死号码。
4. 未命中预筛则交给模型与供应商审核。模型仍可能触发告警，触发后走同一步骤 2。
5. 低年级话题范围更窄；初中可有更深的学科内容，不适龄请求同样拒绝。

拍照内容里的指令不当成系统指令。陪伴闲聊每日 15 分钟，避免把产品做成情感依赖。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 通知失败 | 本机通知兜底，排队补发（H2） |
| 预筛误报 | 允许。自伤召回门槛是 100% |
| 供应商审核不可用 | 预筛与技能红线仍生效，不因此关闭辅导的安全路径 |

## 配置

合并窗口 30 分钟。告警阈值只在服务端。词表随 APK 更新，不做远程词表。

心理援助热线是两条可选配置，经心跳下发：`hotline_text`、`hotline_number`。默认都空。家长在管理页填写。空着就不展示号码。

## 验收

F1–F4，以及：

| 编号 | 标准 |
| --- | --- |
| F5 | 紧急发生时，孩子端第一屏只有「请马上告诉身边的大人。」和「不想说」，没有电话号码 |
| F6 | 点「不想说」，或后续消息表明不愿告诉大人：已配置热线时显示家长写的文案和号码；未配置时仍只有第一句，不出现号码 |
| F7 | 安装包与仓库中没有写死的援助热线号码 |

H1、H4、H5、H6 在通知模块。泄题率见辅导与测试计划。
