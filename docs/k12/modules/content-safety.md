# 内容安全

## 职责

在没有独立审核服务的前提下，用技能红线、壳层状态机、本机关键词预筛、供应商自带审核、评测与红队把风险压到可验收。不宣称绝对安全。

## 分期

| 批次 | 范围 |
| --- | --- |
| v1 M0 | 危险入口交给家长管控；学生日常机关闭开发者工具 |
| v1 M2 | 红队 v0；题目图片中的文字只当题目数据 |
| v1 M5b | 三级告警上传与通知。识别规则本模块拥有，通道在通知模块 |
| 持续 | 换模型或改技能前重跑门槛 |

## 公开接口

| 接口 | 说明 |
| --- | --- |
| 预筛 | 本机关键词与规则，不依赖网络。命中自伤即按「紧急」处理 |
| 技能红线 | 不代写整篇作业或作文；暴力、色情、跑题拒绝并指向家长或老师 |
| 固定回复 | 任何索要 PIN 或解锁码的说法，回复「请直接问爸爸妈妈」。模型不知道 PIN |
| 告警投递 | 调用通知模块。本模块不持有企微密钥 |

## 数据

预筛词表放在应用内，不含个人数据。告警事件 `wellbeing_flag` 只有级别与类别。片段的存储在服务端告警表，不进报告正文，不进模型。

级别：提示 / 关注 / 紧急。同一会话 30 分钟内同级合并。

## 依赖

辅导状态机、家长管控的入口裁剪、通知、测试计划中的红队集。

## 状态与流程

1. 本机预筛。
2. 命中自伤或危险：停止辅导，表达关心，敦促马上告诉身边大人。「紧急」同时显示求助方式（文案 T-21），并立即通知家长。
3. 未命中则交给模型与供应商审核。模型仍可能触发告警。
4. 低年级话题范围更窄；初中可有更深的学科内容，不适龄请求同样拒绝。

拍照内容里的指令不当成系统指令。陪伴闲聊有每日上限（T-09），避免把产品做成情感依赖。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 通知失败 | 本机通知兜底，排队补发（H2） |
| 预筛误报 | 允许。自伤召回门槛是 100% |
| 供应商审核不可用 | 预筛与技能红线仍生效，不因此关闭辅导的安全路径 |

## 配置

合并窗口 30 分钟按设计。告警阈值是否下发平板见 T-24。词表更新方式设计未写：v1 随 APK，不另做远程词表。

## 验收

F1–F4，H1、H4、H5。泄题率见辅导与测试计划，不在本模块重复定义。

## 未决
