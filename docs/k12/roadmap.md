# 路线图

三批发布（ADR-0009）。编码开始前仍须仓库所有者同意。每批上线前过 `test-plan.md` 的门槛。v1 先试点 2–4 周。

| 批次 | 里程碑 | 内容 |
| --- | --- | --- |
| v1 | M0–M3 + M5a + M5b | 薄壳、技能骨架、拍题与揭晓、错题与 FSRS、服务端、配对解锁、告警、日简报模板 |
| v1.1 | M4 + M5e | 背诵听写口语；完整学情报告 |
| v1.2 | M5d | 钉钉同步 + 最小任务列表。先过钉钉 D1–D4。先试方案 A |
| 数据够了再做 | M5f | 亲子建议。依赖 M5e，且至少 4 周真实数据 |
| 后置 | M5c、M6、M7 | 中继扩展；生地模块；作业计划与轻激励 |

规模：S 为单测能罩住的小切片，M 为一个模块内可独立合并的切片，L 为跨端或要联调的切片。不是工期。

依赖写工作包 ID。验收写编号；未决项不当成已通过。
