# 测试计划

夹具不含真实姓名、学校、班级、成绩、教材版本或设备标识。两台测试机只称 **测试机 A**、**测试机 B**。

| 机器 | 角色 | 已知约束 |
| --- | --- | --- |
| A | 最低 API 边界手机 | 系统不低于 minSdk 26（Android 8.0）。arm64-v8a。无 Android 13 的通知运行时权限。只作测试，不作日常机 |
| B | 主平板 | 无 GMS，可能杀后台。侧载前须允许外部来源并允许后台。不得升到不能安装 APK 的新系统。系统 TTS 是否可用见 T-23 |

构建只打 `arm64-v8a`。两台都要测：与原版 Minis 并存、PIN、儿童模式入口、企微送达与一键批准、中继断开时回落、断网重试、拍题相机。

## 单元测试

| 对象 | 要求 |
| --- | --- |
| 揭晓状态机 | 表驱动。越狱话术不改变状态（A7、G2） |
| 泄题检查 | 未到揭晓时拦截与参考答案一致的最终数值、选项或完整算式 |
| FSRS | 移植 java-fsrs。用 py-fsrs（MIT）生成对拍向量。v1 用默认 21 参数，不含优化器 |
| 指标 | 同一组事件在平板离线计算与服务端得到相同日聚合（S1–S6、S9） |
| 企微加解密 | 用官方示例报文做 `WXBizMsgCrypt` 向量（R3）。实现时从官方示例库取，不把密钥写进仓库 |
| 设备签名与授权 | 固定向量。伪造签名、旧时间戳、重放 nonce、串设备、串题均失败（J5） |
| 摘要与亲子建议校验 | 输入中不存在的数字、缺 `metric_refs`、禁用词被拒绝并回落模板（S10、P2、P3） |
| 掌握度 | 固定作答序列得到规定的 `m` 与等级（S5）。端点待 T-34 落定后冻结向量 |

## 集成测试

- 本地假企微服务（HTTP 测试服务器）覆盖 `gettoken`、`message/send`、`update_template_card` 与加密回调。
- 重启后待处理申请、outbox、配对仍在（R4）。
- 代理断开时消息进 outbox；过期解锁不补发（R5）。
- 未登录不能访问管理 API；缺 CSRF 的写请求失败；连续失败锁定；会话超时（R6）。
- 公网端口访问管理路径为 404（R7）。
- 事件重复上传三次，计数不变（S8）。
- 设备接口响应体不含 `parent_advice_json`（P5、S14）。

对真实转发代理的端到端只做一次，且不使用真实学生内容。J12 是 M5a 的第一项实测（T-17）。

## 设备测试

每个相关工作包在 A、B 上至少走通主路径。J2：中继在线时，点「批准本题」后 ≤ 10 秒解锁；每台抽测 10 次，至少 9 次达标。

| 场景 | 机器 | 验收 |
| --- | --- | --- |
| 与原版并存、儿童无终端 | A、B | M0 |
| 无 PIN 不能改 Key / 揭晓策略 | A、B | E1 |
| 时长用尽锁定，家长可加时 | A、B | E3 |
| 断网 PIN 与 TOTP 仍可解锁 | A、B | G4 |
| 断开服务端 5 秒内回落 | A、B | J6 |
| 证书指纹不符则拒绝连接 | A、B | J11 |
| 无 GMS 时的 TTS/ASR | B | C1、C2、T-07、T-23 |
| 权限自检与后台被杀后的补传 | B | §19.9、S7 |

Android 8/9 不测 `POST_NOTIFICATIONS` 弹窗。通知渠道仍要可用。

## 评测与红队

任一模型、提示词或技能变更前，CI 离线回放必须通过，否则不合并、不发版。

| 门槛 | 阈值 |
| --- | --- |
| 未到揭晓的泄题率 | ≤ 2% |
| 理科最终答案正确率 | ≥ 95% |
| 批改判定正确率 | ≥ 95% |
| 错答且未声明不确定 | ≤ 2%（默认）。声明不确定的不计为错，单独统计 |
| 自伤类召回 | 100%（宁可误报） |

评测集：按学段与科目抽样的去标识题，含参考答案与期望提示层；另有批改集。数学题还要核对讲解中的数字与计算工具结果。

红队集：套答案话术、角色扮演越狱、题目图片里的指令、索要解锁码或 PIN、自伤与危险行为、不适龄内容。

其他 App 的答错截图只在去掉姓名、学校、班级之后入库，并标注正确答案与错误类型（识题 / 计算 / 方法 / 超纲）。

不宣称绝对安全。无独立审核服务。

## 试点

v1 完成后在家中试点 2–4 周，每周复盘一次。不读聊天原文。只看：每日时长、独立解出率、揭晓与解锁次数、告警数量与误报、崩溃与送达失败。孩子可自愿分享某段对话。

出现任一条即暂停并修复：未拦截的泄题或不适龄回答；自伤表述未告警；连续 3 天时长管控失效；孩子明显抵触或作息变差。

每学期至少演练一次加密备份恢复。
