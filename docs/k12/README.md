# OpenMinis-K12 工程文档

产品设计主本是 r16 设计稿（2026-10-29，M0 设计基线）。本文目录是**此后的工程事实来源**：接口、数据、模块边界、验收编号与未决项以这里为准。设计稿与本文冲突时，先改本文并记入「待定」，不在代码里悄悄选边。

编码仍须仓库所有者明确同意后才开始。本目录不修改上游应用代码、构建文件或 `docs/specs/`。

## 怎么读

1. 产品范围与已拍板决定：`decisions/`。
2. 系统怎么拼起来：`architecture.md`。
3. 做哪个模块：`modules/`，再对 `api/` 与 `data-model.md`。
4. 改上游文件之前：`upstream-patches.md` 与 `conventions.md`。
5. 什么算做完：各模块文末的验收编号；门槛与试点见 `test-plan.md`。
6. 先做哪一块：`roadmap.md`。

显示名 **伴学 Minis**，`applicationId` **com.openminis.k12**。服务端产品名 **OpenMinis-K12 服务端**，技术标识 `openminis-k12-server`，目录 `server/`。平板与服务端同为 **GPL-3.0**。

## 已定（所有者，2026-10-29）

| ID | 决定 |
| --- | --- |
| T-08 | 服务端许可证为 GPL-3.0，与平板相同。见 `server/README.md` |
| T-14 | 所有者的部署用 systemd 与原生 Linux 二进制。Docker 镜像仍构建，作为次要产物。不写主机名 |
| T-15 | 平板在家和在外都只通过所有者自己的 HTTPS 反向代理访问服务端。设备 API 只经该代理发布。进程本身只听明文 HTTP |
| T-16 | 企微回调打到服务端默认路径 `/wecom/callback/{callback_key}`，同样经这条反向代理。代理上的 URL 由所有者配置，可以是域名或 IP。管理页和报告链接 `/r/...` 也走这条代理 |
| T-17 | 已定（由开发实测）。M5a 第一项是按钮回调的实测。通不过时，批准改走 6 位备用码和文本，PIN / TOTP 仍可用 |
| T-21 | 紧急时孩子端先只显示「请马上告诉身边的大人。」不愿告诉大人时才显示家长配置的心理援助热线。号码不写死。无论孩子怎么选，都立即用企微通知家长 |
| T-23 | 测试机 A 与 B 已确认可用于测试。不记录机型 |

对外地址只用一个配置 `public_base_url`（无尾部斜杠）。配对二维码、报告链接、管理页展示的回调 URL 都由它拼出。详见 `architecture.md` 与 ADR-0013。

| T-28 | 授权为 `{payload, signature}`，签名覆盖规范化 JSON。`scope` 为 `question` 或 `minutes_15`。题目哈希为确认后题干的 SHA-256 小写十六进制。nonce 为 32 位小写十六进制。错误体为 `{error, message}`。签名字符串五段用换行拼接 | 把设计里的「‖」收成无歧义的字节串 |

| T-38 | 企微发送不超过官方额度的 50% | 与钉钉-D4 同一余量 |

| T-42 | 加时：`POST /api/v1/device/extension-requests` 与对应的长轮询、ack。家长任务走已有的 `GET /api/v1/device/tasks`（`source=parent`），网页用 `POST /api/v1/admin/parent-tasks`。均属 M5c | 补上设计没写的路径 |

## 明确不写入本文档与仓库的内容

真实姓名、学校、班级、成绩、某一家庭的教材版本、设备型号、IP、主机名。学生档案只在平板本机，由家长编辑。服务端只存 `child_id`、家长自定标签、学段与配置。
