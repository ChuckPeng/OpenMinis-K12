# J12 / J14 按钮回调现场实测（M5a 第一项）

CI **不能**访问所有者的企业微信。下列步骤由所有者在真实反向代理与企微应用上执行一次，并把结果记在管理页「J12 实测」或审计日志（`j14_button_callback`）。

夹具与通知不含真实姓名、学校或学生内容。

## 所有者需要配置的项（勿把真实值写进仓库）

### 企业微信自建应用

1. 在企业内新建专用自建应用，默认名「伴学助手」。
2. 记录：**CorpID**、**AgentId**、**Secret**。
3. 接收消息服务器：
   - **URL**：管理页显示的回调地址，形如  
     `{public_base_url}/wecom/callback/{callback_key}`  
     （`callback_key` 由服务端生成；整段从管理页复制，不要手改路径。）
   - **Token**、**EncodingAESKey**：与管理页保存的一致（服务端保存后 AESKey 不回显）。
4. 可见范围：默认只含可审批家长对应的成员。
5. 出站 API：家庭侧服务端的 `api_base_url` 指向**固定公网 IPv4 的转发代理**（默认官方基址可改成该代理）。代理至少放行：
   - `/cgi-bin/gettoken`
   - `/cgi-bin/message/send`
   - `/cgi-bin/message/update_template_card`
   - 可选 `/cgi-bin/getcallbackip`

### 反向代理

同一 HTTPS `public_base_url`（无尾斜杠；域名或 IP 均可）：

| 路径 | 上游 |
| --- | --- |
| `/wecom/` | 设备端口（默认 `127.0.0.1:8080`） |
| `/api/v1/admin/`、`/` | 管理端口（默认 `127.0.0.1:8081`） |

`trusted_proxies` 填服务端眼中的代理来源（地址或网段），必填。对外链接只由 `public_base_url` 拼接，不采信 `Host` / `X-Forwarded-Host`。

### 管理页

1. 保存企微配置 → 「测试 gettoken」（成功不回显 token）。
2. 添加至少一名 **可审批** 家长（标签 + 企微 UserId）。
3. 在企微管理后台点「保存」触发 **URL 验证**（GET `echostr`）。应在 1 秒内通过。

## 实测步骤（J12）

1. 管理页「J12 实测」→「创建解锁申请（含备用码）」或使用测试发送按钮卡片（若已接通出站）。
2. 在**企业微信 App**（不是个人微信插件）打开卡片，点「批准本题」。
3. 观察：
   - 服务端审计出现 `template_card_event` / `unlock_approved`；或
   - 管理页将「按钮回调」标为到达。
4. **若按钮点了但服务端无事件**：在管理页点「未到达 → 走备用码」，此后解锁通知以**文本 + 6 位备用码**为主路径；家长把码告诉孩子，孩子在平板输入（PIN/TOTP 仍可用）。也可用管理页「模拟 template_card_event」做无公网联调。

## 通过标准

| 编号 | 标准 |
| --- | --- |
| J12 | `template_card_event` 能到达默认回调路径并完成一次批准，或明确记为不可达 |
| J14 | 若按钮不可达，文本加 6 位备用码仍能完成一次批准 |

实测结论写入工作包，不再另行询问所有者「能不能到」。
