# ADR-0005 企业微信自建应用解锁，PIN 作兜底

- 状态：已接受
- 日期：2026-10-29

## 背景

家长需要不在平板旁边也能放行完整解。群机器人没有按钮回调。个人微信里的模板卡片不显示按钮。

## 决定

在既有企业里新建 K12 专用自建应用，默认名「伴学助手」。出站 API 经固定公网 IPv4 的转发代理。入站回调走 ADR-0013 的 HTTPS 反向代理，路径是服务端默认的 `/wecom/callback/{callback_key}`。

主路径是企微里的「批准本题 / 解锁 15 分钟 / 拒绝」。同一申请带 6 位备用码。平板本机 PIN 必做，TOTP 可选。服务端不可达时 5 秒内回落，解锁申请不排队。

不使用群机器人、PushPlus 或 Server酱。平板不保存企微密钥。

## 后果

按钮回调能否经 HTTPS 反向代理到达，仍要实测（T-17，J12）。可见范围默认只有可审批的家长。`public_base_url` 用域名或 IP 都可以。
