# ADR-0006 平板模型层保持上游原样

- 状态：部分被 [ADR-0015](0015-server-managed-tablet-model.md) 取代
- 日期：2026-10-29

ADR-0015 改的是「家长在平板上填写讲题模型」。下面关于不改 `provider/`、不设默认厂商、不按厂商校验 Base URL、不做金额预算，以及服务端小模型 Key 不下发，仍然有效。

## 背景

上游已经能配置国内模型和自定义供应商。另做一套模型选择会扩大范围。

## 决定

不改 `provider/` 的协议实现，不在本项目里选定默认模型、验证 Base URL 或做金额预算。只在供应商与 Key 页面加家长 PIN。拍题需要视觉模型，写进家长引导即可。

服务端可以另有一个小模型，只用于抽取、报告文字和亲子建议。它的 Key 留在服务端。

换模型或改技能前必须过评测门槛。每孩子每日默认 60 个回合、20 张图片，陪伴闲聊 15 分钟。

## 后果

讲题质量取决于家长所选模型加技能，不取决于本仓库里的供应商代码。
