# ADR-0013 平板与回调共用一个 HTTPS 入口

- 状态：已接受
- 日期：2026-10-29

## 背景

平板有时在家，有时不在家。企微回调、管理页和报告链接也要能从公网打开。服务进程只应听明文 HTTP。

## 决定

所有者提供一条 HTTPS 反向代理。平板在家和在外都只访问这一个 `public_base_url`。设备 API 只经该代理发布。

企微回调使用服务端默认路径 `{public_base_url}/wecom/callback/{callback_key}`，走同一条代理。域名或 IP 由所有者填进 `public_base_url`，仓库不记录具体值。管理页和 `/r/...` 报告链接也走这条代理。

对外 URL 只由 `public_base_url` 拼接。`trusted_proxies` 必填，用来决定是否采信 `X-Forwarded-*`，不用来拼链接。

出站企微 API 仍走单独的固定公网 IPv4 转发代理。那一层不接收设备请求。

## 后果

不再做「家里直连、外面另走隧道」的两条设备路径。J12 仍要实测按钮回调能否到达这条回调 URL（T-17）。
